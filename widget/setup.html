Фокусы дня

Бесплатный маленький виджет для iPhone. Отметки ставятся в «Тренере»; нажатие на виджет открывает приложение.

1

Установи Scriptable

Это бесплатное приложение, которое показывает наш виджет без подписки Apple Developer.

Открыть Scriptable в App Store
2

Добавь скрипт

  1. Нажми «Скопировать скрипт».
  2. В Scriptable нажми +, вставь код и назови его Фокусы дня.
  3. Один раз запусти скрипт — откроется предварительный вид.

3

Выведи на главный экран

  1. Зажми пустое место на экране iPhone → Изменить → Добавить виджет.
  2. Выбери Scriptable и маленький квадратный размер.
  3. Зажми добавленный виджет → Изменить виджет.
  4. Script: Фокусы дня. Parameter: вставь код из раздела «Виджет iPhone» в «Тренере».

Как это работает

После отметки «Тренер» сразу отправляет новые состояния. iOS обновляет виджеты по своему расписанию, поэтому галочка иногда появится не мгновенно. Тап по виджету откроет «Тренер».

Secret Gist не показывается в профиле GitHub, но человек с его длинной ссылкой может прочитать четыре статуса. Другие данные приложения туда не передаются.
