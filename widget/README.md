# Виджет «Фокусы дня» для iPhone

Это бесплатный read-only виджет на базе Scriptable. Пять фокусов отмечаются в «Тренере», а виджет показывает актуальный список; невыполненные остаются сверху, выполненные с зелёной отметкой переходят вниз.

Открой `setup.html` из опубликованного приложения и выполни три шага:

1. Установи Scriptable из App Store.
2. Скопируй `focus-widget.js` в новый скрипт с названием «Фокусы дня».
3. Добавь маленький виджет Scriptable на главный экран, выбери скрипт и вставь Gist ID в поле Parameter.

Важно: iOS сама определяет момент фонового обновления, поэтому новая отметка может появиться с задержкой. Тап по виджету открывает «Тренер».
